# 하늘한칸 (시제품)

접속하면 내가 밤하늘의 드론 불빛 하나가 되고, 정각마다 모두 모여 하나의 그림이 되는 웹 서비스의 시제품입니다.

## 실행

설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.

## 들어 있는 것

- 내 드론 띄우기: 랜덤 이름, 한 줄 소원
- 다른 드론의 소원 말풍선, 드론을 누르면 이름과 소원 보기
- 정각 쇼: 모이기 → 그림 유지 → "내 장면" 메시지 → 흩어지기
- 인원 단계별 그림: 별(0) → 하트(1,000) → 고래(5,000) → 달과 고래(10,000)
- 유료 상품 (테스트 모드, 실제 결제 없음)
  - 드론 색 바꾸기 1,000원
  - 명당 자리 5,000원: 다음 쇼에서 그림의 중심 자리를 금빛으로
  - 내 장면 15,000원: 쇼 중간에 하늘 전체에 내 메시지
- 쇼가 끝나면 내 위치가 표시된 공유 카드 (1080×1920 스토리 크기)
- 친구 부르기 링크 (`#pair-1234`): 친구 드론 옆에서 날기

## 시뮬레이션인 것

- 다른 드론, 접속자 수, 소원은 모두 가짜입니다. 화면 왼쪽 아래 "데모" 상자에서 접속자 수를 바꿔 단계별 그림을 볼 수 있습니다.
- 쇼는 데모용으로 3분마다 열립니다. 실서비스는 매일 밤 10시 한 번입니다 (`SHOW_EVERY_MIN`).
- 결제는 버튼을 누르면 바로 적용되고 돈은 나가지 않습니다.
- 화면에 그리는 드론은 최대 4,000개이고, 그보다 많으면 점 하나가 여러 명을 뜻합니다 (`MAX_VISUAL`).

## 실서비스로 가려면

1. 실시간 서버: 접속자 수, 내 자리 번호, 소원 목록을 모두에게 나눠 주는 서버. 쇼 움직임은 각자 브라우저에서 계산하므로 서버는 "몇 번 자리인지"만 알려 주면 됩니다.
2. 결제 연동: 회원가입 없이 간편결제로 바로 결제되게.
3. 검수: "내 장면" 메시지와 소원 글의 욕설·광고 걸러내기.
4. 배포: 정적 파일 + 실시간 서버.

# 하늘한칸 (시제품)

밤바다 위 하늘에서 접속자 한 명이 드론 불빛 하나가 되고, 정해진 시간에 모두 함께 음악에 맞춘 드론쇼를 펼치는 웹 서비스의 시제품입니다.

## 실행

ES 모듈을 쓰기 때문에 파일을 직접 열지 말고 간단한 웹 서버로 띄워야 합니다.

```bash
cd drone-sky
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀, 스타일 |
| `js/main.js` | 진행 흐름, 화면 조작, 공유 카드, 상점 |
| `js/world.js` | 3D 밤바다: 하늘, 별, 바다 반사, 다리 조명, 도시, 빛 번짐 효과 |
| `js/show.js` | 쇼 순서와 장면별 안무, 드론 이동 |
| `js/formations.js` | 장면 모양 만들기 (구, 꽃, 고래, 글자 등) |
| `js/music.js` | 직접 합성하는 음악 (대기실 음악, 쇼 음악) |
| `vendor/` | three.js 0.160.0 (MIT, `vendor/THREE-LICENSE`) |

## 쇼 순서 (90 BPM, 50마디, 약 2분 13초)

| 마디 | 장면 | 자막 |
|---|---|---|
| 0–4 | 이륙: 바다 위 발사대에서 떠올라 불이 켜짐 | 오늘 하루, 어땠나요? |
| 4–8 | 회전하는 구 | 이 넓은 세상 어딘가에서 |
| 8–12 | 물결 | 흔들리는 날도 있었지만 |
| 12–16 | 피어나는 꽃 | 그래도 꽃은 피었어요 |
| 16–24 | 오늘의 그림 (인원에 따라 별·하트·고래·달과 고래) | 오늘 밤, 우리가 모여 ○○가 됐어요 |
| 24–28 | 참가자 소원 두 개를 글자로 | 오늘 밤, 누군가의 소원 |
| 28–30 | 유료 "내 마음을 하늘에" 메시지 | |
| 30–34 | 모든 불이 꺼지고 내 불빛만 남았다가, 내 주변부터 다시 켜짐 | 이 불빛 하나가 당신이에요 → 그리고, 혼자가 아니에요 |
| 34–36 | 소용돌이로 모임 | 다 함께 |
| 36–38 | 불꽃놀이 세 번 | |
| 38–42 | "오늘도 수고했어요" | 모두에게, 그리고 나에게 |
| 42–46 | 오늘의 그림 다시, 금빛 (공유 카드 촬영) | ○○개의 불빛 중 하나, 바로 당신 |
| 46–50 | 착륙 | 내일 밤 10시에 또 만나요 |

드론 움직임, 색 변화, 박동은 음악과 같은 박자 시계를 씁니다.

## 시뮬레이션인 것

- 다른 드론, 접속자 수, 소원은 가짜입니다. 왼쪽 위 "데모" 상자에서 인원을 바꿔 단계별 그림을 볼 수 있습니다.
- 쇼는 데모용으로 처음 75초 뒤, 이후 2분 30초 간격으로 열립니다. "지금 쇼 시작"으로 바로 볼 수 있습니다.
- 데모에서는 내가 적은 소원이 항상 하늘에 뜹니다. 실서비스에서는 추첨입니다.
- 결제는 테스트 모드입니다. 누르면 바로 적용되고 돈은 나가지 않습니다.
- 음악은 브라우저에서 직접 합성합니다. 실서비스에서는 라이선스를 받은 곡을 쓰는 것을 권합니다.
- 화면에 그리는 드론은 최대 5,000개입니다.

## 실서비스로 가려면

1. 실시간 서버: 접속자 수, 자리 번호, 소원 목록, 쇼 시작 시각을 나눠 줍니다. 쇼 움직임은 각자 브라우저에서 같은 시계로 계산하므로 서버 부담이 작습니다.
2. 결제 연동: 회원가입 없는 간편결제.
3. 검수: 소원과 유료 메시지의 욕설·광고 걸러내기.
4. 음원 라이선스.

# 하늘한칸 (시제품)

밤바다 위 하늘에서 접속자 한 명이 드론 불빛 하나가 되고, 정해진 시간에 모두 함께 음악에 맞춘 드론쇼를 펼치는 웹 서비스의 시제품입니다.

## 실행

ES 모듈을 쓰기 때문에 파일을 직접 열지 말고 간단한 웹 서버로 띄워야 합니다.

```bash
cd drone-sky
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 타이타닉, 1912 특별 회차 (12분 30초)

실제 역사 기록을 따라가며, 침몰을 구경거리로 보여 주지 않고 기억과 위로의 톤으로 구성했습니다.

| 시간 | 장면 | 음악 |
|---|---|---|
| 0:00 | 카운트다운, 이륙, "1912년 4월 10일, 사우샘프턴" | 파도와 뱃고동 |
| 1:40 | 1막 꿈의 배: 네 개의 굴뚝(마지막 하나는 연기가 없는 장식용), 나침반, 바이올린 | 스콧 조플린 「The Entertainer」 |
| 4:20 | 2막 그날 밤: 별이 가득한 잔잔한 바다, 빙산(물 아래가 더 큼), 흰 신호탄 여덟 발 | 망루 종 세 번, 심장 박동 같은 팀파니 |
| 6:40 | 3막 마지막까지: 구명보트 스무 척, 악단 여덟 명과 악보, 불빛 하나 | 「Amazing Grace」 |
| 9:00 | 4막 새벽: 카르파티아호와 해돋이, "1912. 4. 15", "잊지 않을게요", "오늘도 무사히" | 사티 「짐노페디 1번」, 「Amazing Grace」 |
| 11:20 | 착륙 | 「Amazing Grace」 |

「The Entertainer」는 Mutopia Project의 공개 도메인 판본(1902년 원판 복제)에서 선율과 반주를 옮겼습니다.

### 내 음악 파일

데모 상자의 "내 음악 파일"로 갖고 있는 음원을 고르면 그 곡이 브라우저 안에서만 재생됩니다. 기본으로 3막 시작(6:40)부터 흘러나오고, 그동안 기본 음악은 쉬며, 드론 불빛은 곡의 저음 에너지에 맞춰 반짝입니다. 파일은 어디에도 올라가지 않습니다.

## 실제 드론처럼 움직이는 규칙

- 1칸 = 4m 기준, 그림 폭 약 220m
- 모든 드론이 같은 순간에 출발해 같은 순간에 도착하고, 부드럽게 가속·감속 (minimum-jerk 곡선)
- 전환 시간은 가장 멀리 가는 드론 기준으로 계산, 최고 속도 약 초속 5.6m를 목표로 하고 짧은 장면에서는 최대 초속 8~9m
- 가까운 자리끼리 짝을 지어 비행 거리를 줄임
- 비, 불꽃, 지하철, 김처럼 빠른 효과는 드론은 멈춰 있고 조명 순서로 표현

## 시뮬레이션인 것

- 다른 드론, 접속자 수, 소원은 가짜입니다. 왼쪽 위 "데모" 상자에서 인원과 장면을 바꿀 수 있습니다.
- 쇼는 데모용으로 처음 90초 뒤, 이후 2분 30초 간격으로 열립니다. "지금 쇼 시작"으로 바로 볼 수 있습니다.
- 데모에서는 내가 적은 소원이 항상 하늘에 뜹니다. 실서비스에서는 추첨입니다.
- 결제는 테스트 모드입니다.
- 화면에 그리는 드론은 최대 5,000개입니다.

## 실서비스로 가려면

1. 실시간 서버: 접속자 수, 자리 번호, 소원 목록, 쇼 시작 시각 공유. 쇼 움직임은 각자 브라우저에서 같은 시계로 계산.
2. 결제 연동, 소원·메시지 검수.
3. 전용 곡 작곡 의뢰 또는 연주 녹음.
4. 휴대폰 성능 맞춤 (13분 동안 발열·배터리).
